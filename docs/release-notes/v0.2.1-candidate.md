# GADS v0.2.1 — trusted gateway candidate

**Scope:** one injected, fixed-policy GitHub CAS gateway layered on the clean
H-00 v0.2.0 state machine; historical GET-only GitHub provenance probe;
adversarial fake-transport unit suite and standard-library-only GitHub E1.

**New contracts:** verified single Git ref/blob, protected-main source pin,
synthetic reserved budget, exactly one non-force CAS attempt per new transition,
identical-request no-write replay, conflict denied, trusted target run metadata
readback and source correlation requirements.

**Security limitations:** does not install a privileged workflow; no actual
CAS write test against live GitHub; correlation/display_title is not verified
by prior historical target; no external premium request billing cap; scope
checks in code do not constrain contents:write token globally.

**Release status:** candidate; PR/CI and independent security review pending;
not adopted and no protected-main integration.
